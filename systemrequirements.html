SYSTEM REQUIREMENTS

MODULE 01

FUNCTIONAL REQUIREMENTS

FR-01

Categorization

Users shall categorize expenses and specify the number of participants.

FR-02

Group Creation

Users shall create groups and manage members and expenses.

FR-03

Add Expense

Users shall log shared expenses with amount, description and date.

FR-04

Balance Calculation

Automatically calculate balances among group members.

FR-05

Expense Summary

View consolidated expense dashboard and balances.

FR-06

Settlement

Mark debts as paid and update balances instantly.

FR-07

Transaction History

Complete history of expenses and settlement events.

MODULE 02

NON FUNCTIONAL REQUIREMENTS

NFR-01

Performance

System should load pages within 2 seconds.

NFR-02

Security

All user data must be encrypted.

NFR-03

Usability

Interface must remain simple and intuitive.

NFR-04

Reliability

99.99% uptime without unexpected failures.

NFR-05

Availability

Accessible 24/7 across all supported devices.

NFR-06

Data Accuracy

No balance or calculation inconsistencies.

NFR-07

Maintainability

Modular architecture with easy updates.

NFR-08

Compatibility

Works across Chrome, Firefox and Safari.

NFR-09

Scalability

Support growth in users and expense groups.
